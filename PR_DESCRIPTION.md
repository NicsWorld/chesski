🎯 **What:** Missing Input Validation on FEN Parameter. The codebase was previously relying on `chess.js`'s `validateFen` to check FEN strings, which internally uses `split(/\s+/)`.
⚠️ **Risk:** By allowing unvalidated input, it could be exposed to malformed input, regex denial of service (ReDoS), or other validation bugs inside third-party libraries when parsed. An attacker could craft a malicious URL with a payload in the `fen` query parameter to exploit this vulnerability.
🛡️ **Solution:** Implemented a strict regex check before passing the FEN parameter to the `chess.js` validation function. This ensures only properly formatted FEN strings are processed, preventing malformed inputs from being evaluated.
