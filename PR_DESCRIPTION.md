# 🎨 Palette: Improve accessibility for game status and UI toggles

💡 What: Added `aria-live` and `aria-atomic` attributes to status message containers and `aria-pressed` to view, theme, and tutorial toggle buttons.
🎯 Why: Improves screen reader support for dynamically updated text elements and provides semantic feedback on the active state of UI toggles.
📸 Before/After: Not applicable (invisible UX/a11y improvement).
♿ Accessibility: Screen readers will now announce game status updates and recognize when UI toggle buttons are active.
