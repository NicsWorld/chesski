## Description

This PR adds `docs/FEATURE_SUGGESTIONS.md`, which contains a curated, ranked list of 6 highly-scoped, actionable feature ideas for the Chesski product.

The suggestions are tailored to recent codebase contributions and specifically address the goals of driving growth, enabling monetization, and closing existing feature gaps using the established infrastructure.

### Changes Made

- Created `docs/FEATURE_SUGGESTIONS.md` containing 6 formatted feature suggestions:
  1. Premium Themes (Monetization)
  2. PGN Export for Game Sharing (Growth & Retention)
  3. Last Move Highlighting (Core Value / UX)
  4. Move Promotion UI (Closing an Obvious Gap)
  5. Captured Pieces Display (Closing an Obvious Gap)
  6. Interactive Tutorial Progression (Growth / Onboarding)

Each suggestion details the specific repo, surface area, relevant files, current gap, proposed implementation, effort level, user impact, and why it is a suitable targeted task.

### Motivation

To provide concrete, well-scoped tickets to improve the product without requiring massive architectural rebuilds.
