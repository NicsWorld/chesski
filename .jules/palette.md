## 2024-10-13 - Complex ARIA grid structure for board components
**Learning:** For a complex 2D grid like a chessboard to be fully accessible with standard ARIA roles, elements must be carefully nested: a `role="grid"` parent containing wrapper `role="row"` children, which in turn contain `role="gridcell"` children. Adding `gridcell` attributes on flatly mapped items or skipping the `row` elements breaks the hierarchy and makes it inaccessible for screen readers. Using `style={{ display: 'contents' }}` for the `role="row"` wrapper prevents breaking CSS grid layouts.
**Action:** When working with CSS grid grids (like `repeat(8, 1fr)`), explicitly wrap row cells in a `role="row"` wrapper with `display: 'contents'` to fulfill ARIA requirements without altering the visual structure.
