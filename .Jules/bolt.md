## 2024-10-07 - React.memo fails with chess.js primitive pieces due to object equality
**Learning:** `chess.js` `game.get(square)` returns a newly instantiated object on every call or after state changes. Passing this piece object down to a `React.memo` wrapper component breaks memoization because the object reference changes, causing all 64 squares to re-render when dragging a single piece. Additionally, passing `children` containing newly created React elements (like `<Piece>`) breaks memoization.
**Action:** Extract the item rendering logic (e.g. `<Piece>`) into the memoized wrapper component itself. Provide a custom equality function for `React.memo` that explicitly compares the primitive properties of the piece (`piece?.type` and `piece?.color`) rather than the entire object reference.
