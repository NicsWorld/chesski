## 2024-09-10 - Accessibility attributes for status messages and toggles
**Learning:** Dynamic text changes, like game status messages, require `aria-live` and `aria-atomic` to be announced by screen readers without full page reloads. Toggle buttons need `aria-pressed` to semantically indicate their active state.
**Action:** Ensure all dynamically updating textual containers in UI use `aria-live="polite"` and `aria-atomic="true"`, and all toggle buttons use `aria-pressed`.
